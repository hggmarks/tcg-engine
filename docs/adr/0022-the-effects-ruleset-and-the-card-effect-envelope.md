# The Effects Ruleset and the Card Effect envelope

**The derivation.** Phase C builds on a new ruleset, the **Effects Ruleset** (`rulesets/effects-ruleset/`, id `effects`, version 1), derived from the Small Ruleset, which **freezes** as the canonical ruleset of Phase B: its three files, its catalog and its decks do not change from now on, and rule decisions are mirrored in `effects-ruleset.md` and `.yaml` (the mirror rule of `CLAUDE.md` names them). The Effects Ruleset is a copy of the Small Ruleset with two differences: its `meta`, and `effects: true` on `creature` only (Card Effects act only while the card is in `field`, per roadmap #48; a Leader never reaches the `field`, and a mana card never does either, besides having no int field to modify). Its catalog is the Small catalog with `meta: { ruleset: effects, ruleset_version: 1 }`, and carries no Card Effect. Its golden game is the Small Ruleset's Leader-kill game, and a test plays both from the same Seed, decks and Actions and requires equal Event Traces, equal Terminal Outcomes and equal final GameStates.

**The envelope.** A Card Definition's `effects` is a list of Card Effects, each one of two shapes (the draft is one record with every key optional, so that every frontend can express a mixed or an empty element and get the engine's error):

- **Triggered**: `on: <Trigger Matcher>`, an optional `if: <Expression>` and `do: [<Action Effects>]`. A matcher is a single-key map: `enter: <zone>` or `turn_start: {}` (the controller's Turn began; the semantics land in ticket [17], #50). Any other key is kept by the loader as `TriggerMatcherDraft::Other` and rejected by the engine as `UnknownTriggerMatcher`, like `UnsupportedWinCondition` and the old `UnsupportedEffect` before it: the loader reads no meaning (ADR-0008).
- **Continuous**: `while: <Expression>` and `modify: { field, amount }`, an additive int on the carrying card's Card Definition fields (not its instance state): `field` must be a field of the card type (`UnknownModifyField`, also for an instance state) of type int (`ModifyFieldNotInt`), and `amount` an unquoted integer (a quoted or float `amount` is `Malformed` at the key, the number rule of ADR-0009).

**Validation order** (first error wins, ADR-0008, ADR-0009): per card, after its fields, the list against the card type's `effects` flag (`EffectsNotAllowed`, at the list, unchanged from ADR-0009), then each element in order. The shape comes first: keys of both shapes (`on`, `if`, `do` with `while`, `modify`) are `MixedCardEffectShapes`, and neither `on` nor `while` is `MissingCardEffectShape`, both at `cards[x].effects[i]`. A triggered element is then checked at `on` (an unknown matcher; an `enter` zone must exist, `DanglingReference` at `on.enter`), `if` (bool), `do` (`MissingDo`, `EmptyDo`, each effect, then `end_turn`); a continuous one at `while` (bool) and `modify` (`MissingModify`, at `modify`, then the field). Unsupported elements follow below.

**The `self` ref grammar.** Inside a Card Effect (`if`, `while`, `do`) the only name in scope is `self`, the carrying card, typed as the card's own card type (one possible card type). `{ ref: self }` is a Card Ref, `{ ref: self.power }` a Value Ref (a field or an instance state of that card type). This reuses the machinery of ADR-0015 and ADR-0016 without a second grammar: the catalog builds `Refs` with one `ScopedParam { name: self, types: [the card's type] }` through a `pub(crate)` seam in `ruleset_definition` (`SelfScope`, with `check_condition` and `check_effects`), so a Card Effect's conditions and effects are checked by the same code as an action's, with the same `is_card_type` narrowing, and any other name is `DanglingReference` to a param. The error of such a check is a `DefinitionError`; the catalog wraps its kind as `CatalogErrorKind::InvalidCardEffect { error }` and keeps the inner path, rooted at `cards[x].effects[i]` (`cards[goblin].effects[0].if.and[0].eq[1]`).

**`end_turn` is rejected inside `do`**, nested in an `if` effect included (`EndTurnInCardEffect`, at the `end_turn`'s own path, after the effects of `do` were checked). A trigger that re-enters the turn cycle is not covered by the design of how triggers run (ticket [17]); this is unsupported until needed, not a rule that a ruleset can never want it.

**Unsupported until implemented.** No Card Effect executes in this ticket. Validation fully checks and builds each element as a typed `CardEffect` (`Triggered` or `Continuous`, held in `CardDefinition::effects()`), then rejects it, following ADR-0014's `UnsupportedWinCondition` precedent: `UnsupportedTriggeredCardEffect` or `UnsupportedContinuousCardEffect` at `cards[x].effects[i]`, one variant per kind, so that the two can be lifted independently. `CardDefinition::effects()` is therefore always empty today. Ticket [17] lifts the triggered one (and executes triggers), ticket [18] the continuous one (derived reads of fields), by returning no error for that kind in `card_catalog::validate::unsupported` and collecting the effect instead. The ticket that lifts a kind owns the tests of its execution; the checks of the envelope stay as they are.

**Amends** ADR-0009: a card's `effects` is no longer a list of single-key primitive maps whose draft keeps only the name; `EffectDraft` of the catalog and `UnsupportedEffect` are replaced by `CardEffectDraft` and the two Unsupported variants. `EffectsNotAllowed` and the rest of ADR-0009 are unchanged. The loader gains `deny_unknown_fields` on the envelope and on `modify` (an unknown key is a syntax error with a positional path, the precedent of the rest of the catalog) and shares the expression and action effect data-transfer types of the ruleset file, which become visible inside the loader crate. No conflict with another accepted decision; ADR-0004's closed list of field types and its two-stage loading are untouched.

**Amended by ADR-0023:** the triggered rejection is lifted: `UnsupportedTriggeredCardEffect` is deleted (unreachable) and `CardDefinition::effects()` holds the triggered Card Effects. `UnsupportedContinuousCardEffect` stays until ticket [18]. Every other check of the envelope stands.

**Status**: accepted
